Database Schema

📊

InfluxDB (Lokaal)

Time-series database op de Raspberry Pi voor ruwe sensor data.

Measurements:

  • • sensor_reading - temperatuur, humidity
  • • motion_event - beweging true/false
  • • door_event - open/closed

Retention: 14 dagen

☁️

Supabase (Cloud)

PostgreSQL database voor samenvattingen, alerts en configuratie.

Tabellen:

  • • sensor_readings - geaggregeerde data
  • • motion_events - bewegingen per kamer
  • • door_events - deur events
  • • alerts - gegenereerde alerts

Sync interval: 5 minuten

Supabase Tabellen

-- sensor_readings
CREATE TABLE sensor_readings (
  id UUID DEFAULT uuid_generate_v4() PRIMARY KEY,
  entity_id TEXT NOT NULL,
  value FLOAT NOT NULL,
  sensor_type TEXT NOT NULL,  -- temperature, humidity
  room TEXT NOT NULL,
  recorded_at TIMESTAMPTZ DEFAULT NOW()
);

-- motion_events
CREATE TABLE motion_events (
  id UUID DEFAULT uuid_generate_v4() PRIMARY KEY,
  entity_id TEXT NOT NULL,
  room TEXT NOT NULL,
  motion BOOLEAN NOT NULL,
  recorded_at TIMESTAMPTZ DEFAULT NOW()
);

-- door_events
CREATE TABLE door_events (
  id UUID DEFAULT uuid_generate_v4() PRIMARY KEY,
  entity_id TEXT NOT NULL,
  room TEXT NOT NULL,
  is_open BOOLEAN NOT NULL,
  recorded_at TIMESTAMPTZ DEFAULT NOW()
);
