## 🎨 Logo Concept: Shelter + Signal

Het logo combineert:
- **Dak (shelter):** Bescherming, veiligheid, thuis
- **Persoon (stip):** De oudere die thuis woont  
- **Signaal ringen:** "We kijken mee" — zachte monitoring
