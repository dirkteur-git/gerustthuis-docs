## Logo concept: Dun dak, stevig hart

Het logo combineert:
- **Dak (4px lijn):** Bescherming, veiligheid, thuis — subtiel op de achtergrond
- **Hart (7.5px lijn):** Warmte, zorg — wat je voelt
- Eén geheel, twee gewichten — precies zoals GerustThuis werkt
